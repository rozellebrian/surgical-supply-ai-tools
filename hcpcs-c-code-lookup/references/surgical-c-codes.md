# HCPCS C Code Quick Reference — Surgical Implants & OR Supplies
### Last updated: June 2026 | Source: CMS OPPS 2026, hcpcsdata.com

---

## ORTHOPEDIC — FIXATION HARDWARE

| Code | Official Description | What It Covers |
|---|---|---|
| **C1713** | Anchor/screw for opposing bone-to-bone or soft tissue-to-bone (implantable) | Suture anchors, interference screws, bone anchors, cortical screws, cancellous screws, orthopedic washers/nuts, pins for stabilization. **Arthrex, Smith & Nephew anchors**. Also covers synthetic bone substitutes filling bony void. |
| **C1734** | Orthopedic/device/drug matrix for opposing bone-to-bone or soft tissue-to-bone (implantable) | Bone matrix products (NOT antimicrobial). Allograft matrix, DBM putty, bone graft substitute used with fixation. |
| **C1602** | Orthopedic/device/drug matrix/absorbable bone void filler, antimicrobial-eluting (implantable) | Bone void fillers that elute antibiotics (e.g., calcium sulfate + antibiotic beads). Effective July 2025 — can bill with CPT 11012. |
| **C1776** | Joint device (implantable) | Total or partial artificial joint substituting its natural counterpart. Hip, knee, shoulder, elbow, ankle, small joint replacements. **Zimmer Biomet, Stryker, DePuy** total joints. |
| **C1763** | Connective tissue, non-human (includes synthetic) | Xenograft or synthetic tissue used for soft tissue repair/augmentation. Pericardium, dermal allograft from non-human source. |
| **C1781** | Mesh (implantable) | Any implantable mesh (absorbable or non-absorbable) for hernia repair, abdominal wall, pelvic floor. **Medline, Bard, Ethicon** mesh products. |

## SPINAL HARDWARE

| Code | Official Description | What It Covers |
|---|---|---|
| **C1821** | Interspinous process distraction device (implantable) | X-STOP, Superion, DIAM, Coflex, and similar interspinous spacers. |
| **C1713** | Anchor/screw for opposing bone-to-bone or soft tissue-to-bone (implantable) | Also covers pedicle screws, lateral mass screws when used in spinal construct. |
| **C1889** | Implantable/insertable device, not otherwise classified | Use for spinal cages/interbody devices when no specific code is assigned, spinal rods, connectors, and multi-component spinal construct items not individually coded. |
| **C1062** | Intravertebral body fracture augmentation with implant (e.g., metal, polymer) | Kyphoplasty/vertebroplasty implant (balloon, stent, polymer). Balloon kyphoplasty kits (Stryker KyphX, etc.). |

> **Note on spinal cages**: CMS has not always assigned a distinct C code for intervertebral spacers/cages. C1889 NOS is most commonly reported. If a vendor rep says their cage has a specific pass-through code, ask for the CMS OPPS Addendum reference and verify at hcpcsdata.com before using it.

## BIOLOGICALS / BONE GRAFT / MATRICES

| Code | Official Description | What It Covers |
|---|---|---|
| **C1734** | Orthopedic/device/drug matrix (bone-to-bone, soft tissue-to-bone, implantable) | DBM (demineralized bone matrix), allograft putty, bone graft extenders, cancellous chips. **Medtronic Infuse** (rhBMP-2 carrier matrix), **Stryker OP-1 Putty**, **Integra** products. |
| **C1602** | Absorbable bone void filler, antimicrobial-eluting (implantable) | Calcium sulfate + antibiotics, STIMULAN, OsteoSet with tobramycin. |
| **C1763** | Connective tissue, non-human (includes synthetic) | Xenograft patches, bovine pericardium, synthetic collagen implants. |
| **C9399** | Unclassified drugs or biologicals | Use when a specific biological doesn't have its own code. Pairs with a J code in some cases. |

> **CBER/HCT-P products** (e.g., RTI, LifeNet, MTF allografts): These may also be tracked separately under CBER regulations.

## BREAST IMPLANTS

| Code | Official Description | What It Covers |
|---|---|---|
| **C1789** | Prosthesis, breast (implantable) | Saline, silicone, structured breast implants. **Allergan, Mentor, Sientra, Ideal Implant**. Report per implant — bilateral cases = 2 units. |

> **Tissue expanders** (temporary, pre-reconstruction): These may be coded differently and are often bundled with the reconstruction CPT. Verify with the billing team on whether the expander needs a separate C code.

## NEUROSTIMULATORS / SCS

| Code | Official Description | What It Covers |
|---|---|---|
| **C1767** | Generator, neurostimulator (implantable), non-rechargeable | Non-rechargeable pulse generator for spinal cord stimulator, DRG stimulator, peripheral nerve stimulator. |
| **C1778** | Lead, neurostimulator (implantable) | Spinal cord stimulator leads (percutaneous or paddle). Bill per lead. |
| **C1820** | Generator, neurostimulator (implantable), with rechargeable battery and charging system | Rechargeable IPG. Medtronic, Abbott/St. Jude, Boston Scientific recharge systems. |
| **C1607** | Neurostimulator, integrated (implantable), rechargeable with all implantable and external components including charging system | Fully integrated system (IPG + leads + charging) billed as one unit. |
| **C1833** | Electrical stimulation system, radiofrequency powered, implantable components (e.g., receiver and electrode) | RF-powered neurostimulators (older-generation systems). |

## CATCH-ALL / ADMINISTRATIVE

| Code | Official Description | When to Use |
|---|---|---|
| **C1889** | Implantable/insertable device, not otherwise classified (NOS) | No specific code exists for the device. Common for spinal cages, novel implants, multi-component constructs without individual codes. |
| **C1890** | No implantable/insertable device used with device-intensive procedure | Procedure has a J8 indicator but NO implant was actually placed. Tells the payer not to expect device pass-through. |

## PASS-THROUGH CODES — CURRENT (VERIFY QUARTERLY)

Pass-through status is temporary (typically 2–3 years). CMS grants pass-through when a new device costs significantly more than existing payment rates. After the period ends, the device reverts to a bundled or NOS code.

**To verify current pass-through status:**
1. Go to: `https://www.cms.gov/medicare/payment/prospective-payment-systems/hospital-outpatient`
2. Download current OPPS Addendum B (device codes, status indicators)
3. Look for status indicator **J7** = paid separately (pass-through active)

**Or use:** `https://www.hcpcsdata.com/Codes/C/[CODE]` for quick individual code status.
